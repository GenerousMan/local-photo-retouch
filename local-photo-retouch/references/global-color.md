# 全局调色方法

将用户描述转成可观察、可复核的画面目标，再选取适用的常规调色方法。生图工具只用于局部内容修改；本分支通过颜色与明暗变换处理照片。

## 形成处理依据

观察原图与参考图，提取五项信息：目标氛围、主体亮度、明暗关系、颜色关系、必须保护的颜色或细节。把“通透”“柔和”“复古”等词落到这些属性上，不由一个形容词直接推导固定滤镜。缺少参考时做保守调整；只有会显著改变结果的歧义才需要补问。

分清问题的位置和范围：全图偏色、特定颜色、特定亮度区间，或特定对象。全局颜色选区会同时影响相似颜色的不同物体；对象级调整须使用空间蒙版。原有光源颜色与人为偏色的区别结合拍摄语境和参考判断。

## 选择方法和顺序

1. **确认输入。** 核对显示方向、尺寸、ICC、位深及 RAW/已渲染图片。确认可恢复的信息范围和输出用途。色彩管理贯穿输入、显示和输出，不能只改配置标签。[darktable 色彩管理说明](https://docs.darktable.org/usermanual/development/en/special-topics/color-management/overview/)
2. **建立基准。** 根据参考决定曝光、白平衡和主体可读性。RAW 在相应显影工具中处理；已渲染 JPEG/PNG 的处理范围受现有像素信息限制。结合工具的工作色彩空间决定处理顺序，不把某个软件的流程视为所有工具的共同像素管线。[darktable 色彩管线说明](https://docs.darktable.org/usermanual/development/en/special-topics/color-pipeline/)
3. **组织层次。** 按主体与背景的关系调整中间调、明暗端点和对比度。曲线的斜率决定对应亮度区间的对比变化；根据目标区间放置少量控制点。[Adobe Curves](https://helpx.adobe.com/photoshop/desktop/adjust-color/color-corrections/adjust-color-and-tone-with-curves.html)
4. **处理颜色。** 区分白平衡、全局色度、特定颜色调整和按明暗区间着色。根据影响范围选择全局、颜色范围或空间蒙版处理。
5. **复核与统一。** 同时看整图与关键局部。多图先校正各自曝光/色偏，再统一风格，最后逐张检查。

按实际问题阅读 [color-cookbook.md](color-cookbook.md) 的相关条目。该文件以官方教程和文档为依据，给出诊断、操作、保护条件和验收；其中步骤编排是本 skill 的综合方法，不把参数或审美结论归属于官方。

## 执行与验收

组合任务按原图 → 局部精修与校验 → 全局调色处理，保存独立的未调色精修版本；纯调色任务直接从原图开始。处理过程需要空间修正时，仍采用常规像素处理与软蒙版。

先形成一个可审阅预览，检查主体肤色、白色材质、黑发/暗部纹理、相邻色过渡、高光及整体光向。关注新增的纯黑/纯白区域、色域裁切、色带、灰雾和蒙版边缘。直方图用于发现问题，不要求每张照片铺满直方图，也不以单一数字代替视觉验收。

发现问题后只调整相关操作，再另存版本；从原尺寸底图重新运算最终结果。保存实际参数、源文件哈希、输入输出色彩配置和处理报告。全局调色改变全图像素，局部蒙版外一致结论只适用于未调色精修 PNG；JPEG 重压缩也不适用该承诺。

最终对比仅展示实际完成的阶段。纯调色展示“原图 → 调色成片”，组合任务展示“原图 → 精修细节未调色 → 精修且调色”。各阶段采用统一显示色彩空间、相同裁剪坐标和显示尺度，并提供整图与必要的细节对比。

## 工具入口

使用 [scripts/color_grade.py](../scripts/color_grade.py) 前阅读 [color-tools.md](color-tools.md)。配套脚本提供可复现的常规颜色变换及阶段对比导出，默认参数为中性。方法超出其能力时，使用适合的常规修图工具，记录实际操作和参数。
