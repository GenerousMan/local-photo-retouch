# 分区调色

同一种颜色出现在不同物体上，而它们需要不同调整时，先限定空间范围。按照片里的对象、材质或光照区域建立蒙版，再用常规曝光、曲线和颜色调整处理。区域划分与参数由当前照片决定。

## 从目标到区域

明确每个区域需要改变的亮度或颜色、应保留的材质与光感，以及和相邻区域的关系。先建立能兼顾整图的全局基准，再为仍需调整的区域单独设参数。

人物肤色要连着脸、耳、颈部与手一起看，保留受光差异；浅色材质要保留亮部纹理与环境反光；背景亮点的处理要服从构图和光向。用全图判断视觉重点，用局部放大检查边缘和材质。

从原图或未调色精修母版重新执行每版参数。同组照片可以共享光色目标，蒙版和局部补偿逐张确定。多个表情或精修版本沿用同一色彩目标，几何位置变化后重新核对蒙版。

## 准备蒙版

每个区域保存一张静态 8 位灰度 PNG，与按 EXIF 方向显示后的原尺寸底图等大、同坐标。白色完全应用，黑色保持当前像素，灰色按比例混合。先查看蒙版覆盖，再调参数。

可复用 [拼接工具](script-usage.md) 的 `crop` 和 `mask` 命令。将裁剪范围设为整张底图，用 `include` 指定区域、`feather` 调整过渡，并用 `protect` 保护邻近内容。羽化之后再将保护区置零。也可导入从常规修图工具得到的精确蒙版。

蒙版边界跟随实际材质或光照过渡。检查头发、衣物与皮肤交界，避免羽化把肤色调整带入背景，或在轮廓周围留下色环。宽缓的光照调整可以使用渐变蒙版；颜色范围用于进一步限制区域中的选色操作。

## 参数与执行

在现有调色 JSON 中加入 `regions`。下面只展示结构，数值保持中性；需要提供实际蒙版，再按目标填写调整参数。

```json
{
  "version": 1,
  "description": "根据当前照片分别组织主体与材质的光色",
  "regions": [
    {
      "name": "主体区域",
      "mask": "masks/subject.png",
      "opacity": 1,
      "adjustments": {
        "exposure_ev": 0,
        "color_adjustments": []
      }
    },
    {
      "name": "亮部材质",
      "mask": "masks/material.png",
      "opacity": 1,
      "adjustments": {
        "l_curve": [[0, 0], [100, 100]]
      }
    }
  ]
}
```

- `mask` 相对参数文件所在目录解析，也可使用绝对路径。
- `opacity` 为 0 到 1 的整体强度，与蒙版灰度相乘。
- `adjustments` 使用 [常规调色参数](color-tools.md) 中的曝光、通道增益、曲线、饱和度及选色字段，省略的字段保持中性；区域内不再嵌套 `regions`。

脚本先应用顶层全局参数，再按列表顺序逐区处理。每一区域作用于前一步结果，重叠处会累积；通过蒙版与强度控制叠加。混合权重是蒙版灰度与 `opacity` 的乘积，在编码 sRGB 数值上插值。区域的曝光和曲线作用于整个蒙版；`color_adjustments.select` 只进一步限定对应的选色操作。

继续使用 `color_grade.py grade`，命令见 [color-tools.md](color-tools.md)。预览仍传入原尺寸蒙版，脚本会同步缩小图像与蒙版；正式导出从原尺寸母版重新运算，省略 `--preview-max-edge`。

## 验收与交付

检查区域交界、肤色连续性、白色材质层次及背景光色关系。发现局部问题时，调整对应区域的参数、范围或强度，并从同一母版重算。

报告中的 `outside_region_union_changed_pixels` 应为零，它比较分区调整前后的像素，基准是已经完成全局处理的 sRGB 工作图。输入色彩转换和全局调色仍可能改变原图全部像素。各区域还记录实际变化像素数，结合观察确认调整生效。

交付原尺寸成片、实际阶段对比、参数文件及对应蒙版。组合任务继续保留未调色精修版本；调色版本迭代时，可另附前后版本对比，帮助用户判断光色变化。
